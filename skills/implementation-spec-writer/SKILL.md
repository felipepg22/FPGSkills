# Implementation Spec Writer

Create the implementation contract an engineer or coding agent will execute. Produce the specification only; leave task publication and implementation to separate workflows.

1. Read [references/workflow.md](references/workflow.md) completely and follow its intake, evidence, decision, and write sequence.
2. Read [references/spec-schema.md](references/spec-schema.md) completely before drafting. Use its document contract and identifiers.
3. Read [references/readiness.md](references/readiness.md) completely before writing. Validate the complete draft against every applicable check.
4. Create or safely update exactly one Markdown file. Report its path, status, material assumptions, and unresolved decisions.
